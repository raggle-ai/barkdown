# Embedded Markdown

This file is **formatted Markdown** inside a scrollable viewport.

- Headings and lists use the normal document styles.
- Inline `code` and fenced code blocks keep their formatting.
- The content remains in a separate file.

## A Markdown table

| File     | View               |
| -------- | ------------------ |
| Markdown | Formatted document |
| CSV      | Table              |
| TXT      | Source text        |
