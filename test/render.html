BarkDown HTML render test

This file checks how BarkDown displays a local HTML document in the viewer. It is self-contained, so it does not need deleted extension assets.

Expected result: the page renders immediately with readable spacing, code, tables, lists, and links. It must not show a loading state.

Text and links

Inline HTML such as <code> stays readable. Links keep a clear style, for example open the feature test.

HTML documents run inside a sandboxed iframe. The test must stay useful without JavaScript.

Lists

  • Clear bullet spacing
  • Enough contrast on light backgrounds
